AI業務改善ハンター Web v1.0

内容：index.html / style.css / app.js / manifest.webmanifest / icon.png / icon-512.png
サーバー不要の静的HTML/CSS/JavaScript。API不要、追加課金不要。

公開：GitHub PagesなどのHTTPS対応静的ホスティングに、ZIP解凍後のファイルを同じフォルダ構成でアップロード。
index.htmlをトップとして公開します。

Safariの「共有」→「ホーム画面に追加」でアイコンを作成できます。
お気に入り、ステータス、マイ業務は端末のlocalStorageに保存されます。Webサイトデータ削除、プライベートブラウズ、別端末利用などではデータが失われたり共有されない場合があります。保存画面からJSONバックアップを出力できます。

「新しい改善案を探す」は調査文をクリップボードへコピーしChatGPTを別画面で開きます。自動送信・結果自動反映はできません。

公開事例8件は2026年10月時点で会話中に提示された企業事例と出典URLを初期登録したものです。掲載数値は企業公表値であり独立検証や導入成果の保証ではありません。別途8件の仮想サンプルを含みます。

注意：業務上の機密情報は公開リポジトリや個人用ChatGPTへ入力しないでください。

【v1.1更新】検索ボタンは調査文をコピーするだけです。ChatGPTのWebログイン画面は開きません。iPhoneのホーム画面からChatGPTアプリを手動で起動して貼り付けてください。
【保存データ】localStorageのhunter_saved / hunter_status / hunter_profileのキーは変更していません。同じGitHub Pages URLを更新すれば従来の保存内容を引き継げます。更新前にJSONバックアップ推奨。
