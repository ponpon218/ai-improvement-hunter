AI業務改善ハンター v1.3

新機能：ChatGPTの回答から「登録用JSON」をコピーし、改善事例を追加。

更新：GitHubのリポジトリ直下の同名7ファイルを置換してください。既存のhunter_saved / hunter_status / hunter_profileキーは変更しません。追加事例はhunter_customに保存します。

使い方：アプリで調査文をコピー→ChatGPTで調査→気に入った事例の「登録用JSON」コードブロックをコピー→アプリの「改善事例を追加」に貼り付け→内容を確認して登録。

バックアップ：保存タブで「全データをJSONでバックアップ」。復元は既存データを置き換えるので注意。

注意：iPhoneのホーム画面アプリは別のアイコンを作ると保存領域が分かれる場合があります。旧アイコンは移行確認まで削除しないでください。
